    On considère
    🔗
    \begin{equation*} f:P\in\mathbb{R}_3[X]\mapsto \jmat{P(0)\\ 2P'(1)}\in\mathbb{R}^2 \end{equation*}

    1.

      \(f\) est linéaire.
      🔗
      🔗

    • True.

    • Soient \(P,Q\in\mathbb{R}_3[X], \lambda\in\mathbb{R}\) . On calcule
      \begin{align*} f(P+\lambda Q) \amp =\jmat{ P(0)+\lambda Q(0)\\ 2(P+\lambda Q)'(1)}\\ \amp =\jmat{P(0)+\lambda Q(0)\\ 2(P'(1)+\lambda Q'(1)})\\ \amp =\jmat{P(0)\\ 2P'(0)}+\lambda \jmat{Q(0)\\ 2Q'(0)}\\ \amp =f(P)+\lambda f(Q) \end{align*}
      On a donc bien
      \begin{equation*} \text{Pour tout } P,Q\in\mathbb{R}_3[X],\text{Pour tout }\lambda\in\mathbb{R},f(P+\lambda Q)=f(P)+\lambda f(Q) \end{equation*}
      donc \(f\) est linéaire.

    • False.

    • Soient \(P,Q\in\mathbb{R}_3[X], \lambda\in\mathbb{R}\) . On calcule
      \begin{align*} f(P+\lambda Q) \amp =\jmat{ P(0)+\lambda Q(0)\\ 2(P+\lambda Q)'(1)}\\ \amp =\jmat{P(0)+\lambda Q(0)\\ 2(P'(1)+\lambda Q'(1)})\\ \amp =\jmat{P(0)\\ 2P'(0)}+\lambda \jmat{Q(0)\\ 2Q'(0)}\\ \amp =f(P)+\lambda f(Q) \end{align*}
      On a donc bien
      \begin{equation*} \text{Pour tout } P,Q\in\mathbb{R}_3[X],\text{Pour tout }\lambda\in\mathbb{R},f(P+\lambda Q)=f(P)+\lambda f(Q) \end{equation*}
      donc \(f\) est linéaire.

    🔗
    \begin{equation*} f:M\in \mathcal{M}_n(\mathbb{R})\mapsto M^2 + 3M\in\mathcal{M}_n(\mathbb{R}) \end{equation*}

    Exercice Exercice 6

    On considère
    🔗
    \begin{equation*} f:M\in\mathcal{M}_n(\mathbb{R}) \mapsto M^\top+M \in\mathcal{M}_n(\mathbb{R}) \end{equation*}

    1.

      \(f\) est linéaire.
      🔗
      🔗

    • True.

    • Soient \(M_1,M_2\in\mathcal{M}_n(\mathbb{R}), \lambda\in\mathbb{R}\) . On calcule
      \begin{align*} f(M_1+\lambda M_2) \amp =(M_1+\lambda M_2)^\top+(M_1+\lambda M_2)\\ \amp =M^\top_1+\lambda M_2^\top+M_1+\lambda M_2\\ \amp =(M^\top_1+M_1)+\lambda (M^\top_2+M_2)\\ \amp =f(M_1)+\lambda f(M_2) \end{align*}
      On a donc bien
      \begin{equation*} \text{Pour tout } M_1,M_2\in\mathcal{M}_n(\mathbb{R}),\text{Pour tout }\lambda\in\mathbb{R},f(M_1+\lambda M_2)=f(M_1)+\lambda f(M_2) \end{equation*}
      donc \(f\) est linéaire.

    • False.

    • Soient \(M_1,M_2\in\mathcal{M}_n(\mathbb{R}), \lambda\in\mathbb{R}\) . On calcule
      \begin{align*} f(M_1+\lambda M_2) \amp =(M_1+\lambda M_2)^\top+(M_1+\lambda M_2)\\ \amp =M^\top_1+\lambda M_2^\top+M_1+\lambda M_2\\ \amp =(M^\top_1+M_1)+\lambda (M^\top_2+M_2)\\ \amp =f(M_1)+\lambda f(M_2) \end{align*}
      On a donc bien
      \begin{equation*} \text{Pour tout } M_1,M_2\in\mathcal{M}_n(\mathbb{R}),\text{Pour tout }\lambda\in\mathbb{R},f(M_1+\lambda M_2)=f(M_1)+\lambda f(M_2) \end{equation*}
      donc \(f\) est linéaire.

    🔗
    Si \(f\) est linéaire, donner \(\dim\Ker(f)\) et \(\rg(f)\text{.}\) Sinon, entrer \(-1\text{.}\)
    🔗

    3.

    On ne suppose plus que \(n=2\text{.}\)
    🔗
    Sélectionner les affirmations correctes.
    🔗
    🔗
    • \(f\) est injective.
    • Montrons que \(\Ker(f)\neq \{0_{\mathcal{M}_n(\mathbb{R})}\}\) ce qui montrera que \(f\) n’est pas injective.
      Posons
      \begin{equation*} M=\jmat{ 0 \amp 1 \amp \ldots \amp 0\\ -1 \amp 0 \amp \amp \vdots\\ \vdots \amp \amp \ddots \amp \\ 0 \amp \ldots \amp 0 \amp 0} \end{equation*}
      Alors
      \begin{equation*} f(M)=M^\top+M=\jmat{ 0 \amp -1 \amp \ldots \amp 0\\ 1 \amp 0 \amp \amp \vdots\\ \vdots \amp \amp \ddots \amp \\ 0 \amp \ldots \amp 0 \amp 0 }+\jmat{ 0 \amp 1 \amp \ldots \amp 0\\ -1 \amp 0 \amp \amp \vdots\\ \vdots \amp \amp \ddots \amp \\ 0 \amp \ldots \amp 0 \amp 0 }=0_{\mathcal{M}_n(\mathbb{R})} \end{equation*}
      Donc \(M\neq 0_{\mathcal{M}_n(\mathbb{R})}\) et \(M\in \Ker(f)\text{,}\) ce qui montre que \(f\) n’est pas injective.
    • \(f\) n’est pas surjective.
    • Montrons que \(\Im(f)\neq \mathcal{M}_n(\mathbb{R})\text{.}\)
      Pour cela, considérons à nouveau la matrice
      \begin{equation*} M=\jmat{0 \amp 1 \amp \ldots \amp 0\\-1 \amp 0 \amp \amp \vdots\\\vdots \amp \amp \ddots \amp \\0 \amp \ldots \amp 0 \amp 0 } \end{equation*}

      \begin{equation*} f(A)=M \text{ i.e. } A^\top+A=M \end{equation*}
      mais alors on aurait
      \begin{equation*} (A^\top+A)^\top=M^\top \Leftrightarrow A+A^\top=M^\top=-M \end{equation*}
      ce qui donne \(M=-M\text{.}\)
      donc \(M=0_{\mathcal{M}_n(\mathbb{R})}\text{,}\) ce qui est une contradiction.
      Donc \(M\notin \Im(f)\text{,}\) donc \(f\) n’est pas surjective.
    • \(f\) n’est pas un isomorphisme linéaire
    • \(f\) n’est ni injective, ni surjective, donc pas bijective. Ce n’est pas un isomorphisme.
    • \(f\) est un endomorphisme.
    • Les espaces vectoriels de départ et d’arrivée de \(f\) sont les mêmes et \(f\) est linéaire donc \(f\) est un endomorphisme.
